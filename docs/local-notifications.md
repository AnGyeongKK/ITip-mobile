# 로컬 시연 완료 알림

```text
Android WorkManager
  → 기기에서 자막 수집 (한 번에 1개)
  → 기존 업로드 API로 자막 전송·분석 접수
  → 로컬 Docker API에서 배치 상태 조회
  → Android 완료 알림
  → 알림 탭으로 분석 결과 또는 배치 화면 열기
```

## 실행 설정

- API·Worker·PostgreSQL은 기존 로컬 Docker 구성을 사용한다. 백엔드의 `FCM_PUSH_ENABLED=false`를 유지한다.
- 앱은 `EXPO_PUBLIC_USE_MOCK=false`, 에뮬레이터의 API 주소를 `http://10.0.2.2:18080`으로 설정한다. 실제 포트가 다르면 그 값을 사용한다.
- 로컬 완료 알림은 기본값이다. `EXPO_PUBLIC_NOTIFICATION_MODE=fcm`을 지정하면 기존 FCM 기기 등록 방식으로 동작한다.
- Kotlin과 WorkManager가 추가됐으므로 개발용 APK를 다시 빌드·설치한다. Metro 새로고침만으로 네이티브 코드를 추가할 수 없다.
- 앱의 **메뉴 → 알림 설정**에서 권한을 허용한다. 서버는 노트북에서 계속 실행하며, 에뮬레이터나 기기가 로컬 API에 접근할 수 있어야 한다.

## 앱을 닫았을 때

WorkManager가 수집·업로드·상태 조회를 저장하고 실행한다. 진행 중에는 상태 알림이 표시된다. 홈으로 이동하거나 최근 앱에서 화면을 닫아도 작업은 이어진다. 프로세스가 시스템에 의해 종료되면 Android가 작업을 다시 예약할 수 있으며, 재개 시점은 시스템 상태에 따라 달라진다.

Android 설정의 **강제 종료**, 기기 전원 끄기, 앱 삭제는 실행을 중단한다. 강제 종료 후에는 사용자가 앱을 다시 열어야 한다.

## 중복·실패 처리

- 배치별 WorkManager 작업을 하나만 등록한다. 직접 수집과 백그라운드 수집은 같은 잠금을 사용한다.
- 수집 제한을 받으면 기기 전체 수집을 멈춘다. **자막 수집 재개/다시 시도**를 누른 경우에만 제한을 해제한다.
- 자막은 앱 내부 임시 파일에 쓴 뒤 확정한다. 업로드가 끝난 ID와 고정된 분석 접수 키를 보관해 응답 유실 시 재사용한다.
- 자막의 끝 시간이 영상 길이를 초과하면 영상 끝에 맞춘다. 문장을 유지하고, 음수·길이 0·시작 시간 역순은 오류로 처리한다.
- 일시적 네트워크 실패는 최초 포함 최대 3회 처리한다. 이후에는 앱에서 연결 상태를 확인하고 재개한다. 한 번의 백그라운드 실행은 최대 1시간이다.
- 로컬 방식은 현재 시연용 고정 사용자 API를 사용한다. 사용자 인증을 활성화할 때에는 백그라운드 토큰 보관·갱신을 함께 구현한다.
